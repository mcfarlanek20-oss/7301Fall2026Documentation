**WordPress Installation and Configuration**
Created a new virtual machine with additional resources.
Reinstalled the LAMP stack and MySQL.
Downloaded and extracted the WordPress installation files.
Installed the unzip utility to extract the files.
Configured www-data permissions for WordPress files and directories.
Created an uploads directory and granted write access.
Created a MySQL user for WordPress.
Granted the user permissions to access the WordPress database.
Added database credentials to wp-config.php.
Completed the installation through the WordPress web interface.
